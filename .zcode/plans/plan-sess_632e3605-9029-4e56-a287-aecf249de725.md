# خطة إصلاح وتحسين نظام الحضور والانصراف — ويب + موبايل

## الأخطاء المكتشفة

### ويب (admin_web):
1. **BUG حرج في `AttendanceDrilldownPage.tsx`**: الـ `useHrPrefix` مستورد (سطر 31) لكن غير مستدعى. روابط الموظف تستخدم مسار hardcoded `/hr/employees/` (سطر 369) بدلاً من `hrPrefix` — يكسر التوجيه عندما المستخدم في سياق `/admin/hr` (المدير العام).
2. **كود ميت**: `AttendanceRosterDialog.tsx` + `useAttendanceRoster` hook + اختبارها — غير مستخدمة في أي مسار أو صفحة، تعقّد الكود.

### موبايل (mobile_flutter):
3. **لا يوجد drilldown** — `ExecutiveAttendanceTab` يعرض قائمة مسطحة بكل الموظفين مجمّعة حسب القسم. الشرائح (chips) الملخصة (حضر/متأخر/غائب/مأمورية/إجازة) غير قابلة للنقر لفلترة القائمة. لا يوجد بحث. المدير (`manager_home_page`) لديه `_TeamAttendanceCard` بأرقام ثابتة بدون نقر.

## خطة التنفيذ

### المرحلة 1: إصلاح ويب — `AttendanceDrilldownPage.tsx`
- **استدعاء `useHrPrefix()`** داخل مكوّن `AttendanceDrilldownPage`
- **تمرير `hrPrefix` كـ prop** إلى مكوّن `Row` (الذي معرّف خارج المكوّن الرئيسي)
- **استخدام `${hrPrefix}/employees/${item.employeeId}`** في الرابط بدلاً من المسار hardcoded
- **حذف الـ import غير المستخدم** إن لم يعد ضرورياً بعد الإصلاح
- تشغيل `tsc -b` للتأكد من عدم وجود أخطاء

### المرحلة 2: حذف الكود الميت — ويب
- حذف `AttendanceRosterDialog.tsx`
- حذف `__tests__/AttendanceRosterDialog.test.tsx`
- حذف `useAttendanceRoster` hook من `useAttendanceDashboard.ts` (مع ترك `useAttendanceRosterPage` و`useAttendanceDashboard`)
- حذف `mockAttendanceRoster` من `domainMocks.ts` إن لم تعد مستخدمة
- تشغيل الاختبارات للتأكد من عدم كسر شيء

### المرحلة 3: تحسين الموبايل — `ExecutiveAttendanceTab`
تحويل الـ tab المسطّح إلى تجربة تفاعلية كاملة:

**أ. فلترة بالشرائح (Category Filter Chips):**
- جعل شرائح `_SummaryBar` قابلة للنقر
- إضافة شريحة "الكل" لإظهار الجميع
- عند النقر على شريحة (مثلاً "متأخر")، تُفلتر القائمة لتعرض الموظفين المتأخرين فقط
- تمييز الشريحة النشطة بصرياً (خلفية ممتلئة بدلاً من شفافة)
- إضافة `onCategoryTap` callback و `selectedCategory` state في `ExecutiveAttendanceTab`

**ب. البحث:**
- إضافة `SearchAnchor` / `TextField` أعلى القائمة
- فلترة فورية بالاسم/الكود الوظيفي/القسم أثناء الكتابة
- دمج البحث مع فلترة الشريحة (يعملان معاً)

**ج. تحسين UI/UX:**
- تحسين تصميم البطاقات (status badge أوضح، أيقونات أجمل)
- إضافة شريط حالة علوي ملون يعكس نسبة الحضور
- تحسين الـ bottom sheet التفصيلي للموظف
- إضافة badge "مأمورية" و"إجازة" كشرائح مستقلة قابلة للنقر

### المرحلة 4: تحسين الموبايل — Manager `_TeamAttendanceCard`
- جعل البطاقة قابلة للنقر (`InkWell` + `onTap`)
- عند النقر، الانتقال إلى `ExecutiveAttendanceTab` (أو نسخة مفلترة بالفريق)
- إضافة مفتاح `"manager_attendance"` للتنقل

### المرحلة 5: اختبارات ويب
- تشغيل `npx tsc -b --pretty false` — يجب أن يكون نظيف
- تشغيل `npx vitest run src/features/attendance` — يجب أن تجتاز كل الاختبارات
- إضافة اختبار للتأكد من أن `AttendanceDrilldownPage` يعرض روابط صحيحة
