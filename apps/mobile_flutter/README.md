# Flutter Unified App

تطبيق واحد يحدد التجربة من `get_my_access_context`:

- Employee Workspace.
- Manager Workspace مع الوظائف الشخصية.
- Executive Workspace بلا بصمة شخصية أو إرسال موقع/فيديو.

لا يعتمد التطبيق على أسماء الأدوار لتنفيذ الأمان؛ الأمان الحقيقي داخل RLS/Edge Functions، بينما Access Context يحدد العرض والتنقل.
