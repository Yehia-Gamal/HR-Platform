1. **نشر Migration `0738` و`0739` على staging/production واختبار pgTAP:** Docker وحاوية Supabase المحلية غير متاحة هنا، لذلك لم يُشغّل `supabase db reset` ولا `supabase test db`، وتخطّى `check-function-refs.mjs` فحص المراجع بتحذير.
2. **قرص WSL2 في `.temp/lifecycle-wsl/debian/ext4.vhdx` (`6.36 GB`):** مرتبط بتوزيعة ويندوز مسجّلة باسم `HRPlatformAuditDebian` (`Stopped`). بقي محفوظاً لحين قرار صريح بإلغاء تسجيله (`wsl --unregister HRPlatformAuditDebian`).
3. **إعادة كتابة تاريخ `.git/` (`87.18 MB`):** يحوي التاريخ القديم 3 ملفات APK مرفوعة سابقاً (`~56–60 MB` للملف)، ولم يُلمس التاريخ التزاماً بقواعد الأمان.
4. **توحيد قاموس الصلاحيات في DB ودمج المساحتين `/hr` و`/admin/hr`:** تغييرات معمارية ومنتجية واسعة في الواجهة والـRLS تتطلب اعتماداً مستقلاً وخطة ترحيل على staging أولاً.
5. **دعم iOS الفعلي واختبارات الأجهزة الحقيقية (GPS / Passkeys / FCM / E2E Playwright):** لا تتوفر أجهزة أو محاكيات في بيئة التدقيق الحالية، و`apps/mobile_flutter/ios/README.md` يوثّق حالة iOS.
