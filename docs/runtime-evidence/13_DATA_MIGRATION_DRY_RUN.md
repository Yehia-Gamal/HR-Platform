- Dry Run أولًا لاستيراد: الموظفين، الإدارات/الفرق/المناصب، المديرين، المردودات، أرصدة الإجازات،
  الحضور التاريخي، العقود/المستندات، الأدوار/الصلاحيات.
- اكتشاف التكرار حسب كود الموظف/البريد/الهاتف.
- عدم إنشاء مدير غير موجود.
- تقرير لكل سجل مرفوض + Reconciliation بعد الاستيراد + Rollback plan + توقيع HR.
