# المهمة 07 — الإجازات والأذونات والتكليفات والتصحيحات والعطلات

## قواعد مشتركة ملزمة

- المرجع الوظيفي هو خطة V22 المختصرة والمحصنة، وهذه المهمة جزء منها وليست مشروعًا منفصلًا.
- العمل داخل المستودع الحالي ونفس Flutter/Web/Supabase/Firebase/Package Name/Keystore.
- ابدأ بـDiscovery داخل نطاقك قبل التعديل، ولا تفترض أسماء ملفات أو جداول أو دوال.
- لا تعدّل Migration منشورة، ولا تحذف بيانات Production، ولا تعطّل RLS.
- استخدم Migration جديدة باسم Timestamp UTC كامل بعد حجزها في سجل التنسيق.
- لا تعرض بيانات Demo أو نجاحًا وهميًا.
- لا تكتب «تم» دون Root Cause، Commit، Tests، Runtime Evidence، وRollback.
- لا تعدّل ملفات مملوكة لوكيل آخر دون موافقة Orchestrator وتحديث File Ownership Registry.
- كل واجهة جديدة يجب أن ترتبط بخادم فعلي وصلاحيات واختبارات.
- عند خطر فقد بيانات: أوقف الجزء الخطر فقط، سجله في BLOCKERS، واستمر في المهام المستقلة.
- سلّم تقريرًا ختاميًا يتضمن: قبل/بعد، الملفات، المايجريشن، الاختبارات، الصور، السجلات، القيود، وخطوات الرجوع.

## الواجهة

اسم التنقل:

**طلب إجازة**

عنوان المركز:

**الإجازات والتكليفات**

Tabs:

- الإجازات.
- أذونات الحضور والانصراف.
- تصحيحات الحضور.
- تكليفات العمل: مأمورية/قافلة/فاندي.

## الأرصدة

إعدادات قابلة للتعديل ومراجعة قانونيًا:

- اعتيادية 15.
- عارضة 6.
- مرضية يومان شهريًا وفق السياسة.
- أكثر من 50 سنة أو خدمة/تأمين >10 سنوات: 30 = 20 اعتيادية +10 عارضة.

## العارضة

تلقائية فقط إذا:
`emergency_leave_auto_approval_enabled = true`

مع رصيد/عدم تداخل/Audit/إشعار.
وإلا تسلك مسار المدير.

## الأنواع المعطلة

- وضع.
- رعاية طفل.

تحفظ البيانات التاريخية.

## التصعيد

- مدير الموظف Executive: بعد 6 ساعات إلى Operations مخول.
- مدير آخر: بعد 12 ساعة إشعار السكرتير؛ تمديد/نقل/Break-glass.
- لا اعتماد ذاتي.
- المدير يحدد Backend لا باختيار الموظف.

## التكليفات

- Mission/Convoy/Funday.
- عمل رسمي.
- لا خصم رصيد.
- لا غياب.
- لا ساعات سلبية في الجزء المغطى.
- التكليف الجزئي يغطي ساعاته فقط.
- المدير ينشئ لفريقه.
- Operations/Main Admin حسب النطاق.
- تقارير بعد العودة عند الحاجة.

## تصحيحات الحضور

- حضور مفقود.
- انصراف مفقود.
- وقت/موقع/حالة خاطئة.
- Employee → Manager → HR.
- Correction event دون تعديل الخام.
- إعادة حساب الشهر وKPI.

## الإجازات الرسمية

- الجميع/إدارة/فريق/فرع/أفراد واستثناءات.
- لا غياب ولا خصم ولا تذكير.
- منشور وإشعار.
- Audit.

## اختبارات

- جميع الأنواع والحالات العربية.
- لا reload بين tabs.
- RLS.
- لا خصم للتكليفات.
- التصعيد الصحيح.
- Operations لا يعتمد طلبه.
- إجازة جزئية وتكليف جزئي.
- تحديث الحضور والتقارير.
