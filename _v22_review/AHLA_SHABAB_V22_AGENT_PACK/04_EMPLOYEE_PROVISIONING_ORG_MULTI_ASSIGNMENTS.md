# المهمة 04 — الموظفون والهيكل والتعيينات المتعددة

## قواعد مشتركة ملزمة

- المرجع الوظيفي هو خطة V22 المختصرة والمحصنة، وهذه المهمة جزء منها وليست مشروعًا منفصلًا.
- العمل داخل المستودع الحالي ونفس Flutter/Web/Supabase/Firebase/Package Name/Keystore.
- ابدأ بـDiscovery داخل نطاقك قبل التعديل، ولا تفترض أسماء ملفات أو جداول أو دوال.
- لا تعدّل Migration منشورة، ولا تحذف بيانات Production، ولا تعطّل RLS.
- استخدم Migration جديدة باسم Timestamp UTC كامل بعد حجزها في سجل التنسيق.
- لا تعرض بيانات Demo أو نجاحًا وهميًا.
- لا تكتب «تم» دون Root Cause، Commit، Tests، Runtime Evidence، وRollback.
- لا تعدّل ملفات مملوكة لوكيل آخر دون موافقة Orchestrator وتحديث File Ownership Registry.
- كل واجهة جديدة يجب أن ترتبط بخادم فعلي وصلاحيات واختبارات.
- عند خطر فقد بيانات: أوقف الجزء الخطر فقط، سجله في BLOCKERS، واستمر في المهام المستقلة.
- سلّم تقريرًا ختاميًا يتضمن: قبل/بعد، الملفات، المايجريشن، الاختبارات، الصور، السجلات، القيود، وخطوات الرجوع.

## إنشاء الموظف

عند الإنشاء:

- حالة العمل `active`.
- يظهر فورًا في الدليل والحضور والهيكل وتطبيق Executive.
- حالة الدخول منفصلة:
  - لم يسجل بعد.
  - إعداد كلمة المرور.
  - جاهز.
- لا تعرض «تحت الدعوة» كحالة وظيفية.

## صلاحيات الإنشاء

- HR: Employee/Direct Manager/Operations فقط.
- Main Admin: جميع الأدوار والعضويات العليا.
- التحقق Server-side.

## إدارة الموظف

- تعديل البيانات.
- تغيير المدير.
- تغيير الوظيفة.
- إدارة الإدارات.
- تعطيل.
- أرشفة.
- استعادة.
- حذف آمن.
- إدارة الجهاز.

Permanent delete لـMain Admin فقط، ومع وجود تاريخ يتحول لأرشفة.

## التعيينات المتعددة

### P0

- Primary assignment واحد.
- Secondary assignments متعددة.
- الطلبات والحضور وKPI تعتمد الأساسي.
- الموظف يظهر مرة واحدة.

### P1

- نسب تخصيص.
- مدير وظيفي ثانوي.
- تقارير توزيع الوقت.

## الهيكل الوظيفي

- Tree + List fallback.
- بحث.
- صور.
- الوظيفة والإدارة والمدير.
- الوظائف الإضافية.
- Timeout/Retry/Cache.
- لا spinner بلا نهاية.
- كشف العلاقات الدائرية.

## صور الموظفين

Avatar موحد في:

- الرئيسية.
- الدليل.
- الفريق.
- الحضور.
- الطلبات.
- KPI.
- القضايا.
- الموقع.

## اختبارات القبول

- موظف جديد = نشط.
- يظهر في كل المصادر الموحدة.
- HR لا يمنح دورًا عاليًا.
- موظف بوظيفتين لا يتكرر.
- طلبه يذهب للمدير الأساسي.
- تغيير المدير لا يمحو التاريخ.
- RLS حسب النطاق.
