# المهمة 08 — KPI والمسار المتوازي

## قواعد مشتركة ملزمة

- المرجع الوظيفي هو خطة V22 المختصرة والمحصنة، وهذه المهمة جزء منها وليست مشروعًا منفصلًا.
- العمل داخل المستودع الحالي ونفس Flutter/Web/Supabase/Firebase/Package Name/Keystore.
- ابدأ بـDiscovery داخل نطاقك قبل التعديل، ولا تفترض أسماء ملفات أو جداول أو دوال.
- لا تعدّل Migration منشورة، ولا تحذف بيانات Production، ولا تعطّل RLS.
- استخدم Migration جديدة باسم Timestamp UTC كامل بعد حجزها في سجل التنسيق.
- لا تعرض بيانات Demo أو نجاحًا وهميًا.
- لا تكتب «تم» دون Root Cause، Commit، Tests، Runtime Evidence، وRollback.
- لا تعدّل ملفات مملوكة لوكيل آخر دون موافقة Orchestrator وتحديث File Ownership Registry.
- كل واجهة جديدة يجب أن ترتبط بخادم فعلي وصلاحيات واختبارات.
- عند خطر فقد بيانات: أوقف الجزء الخطر فقط، سجله في BLOCKERS، واستمر في المهام المستقلة.
- سلّم تقريرًا ختاميًا يتضمن: قبل/بعد، الملفات، المايجريشن، الاختبارات، الصور، السجلات، القيود، وخطوات الرجوع.

## المسار الوحيد

```text
السكرتير يفتح الدورة
→ الموظف يقيّم نفسه ويرسل
→ HR والمدير يعملان بالتوازي على حقول منفصلة
→ Barrier بعد اكتمالهما
→ السكرتير يراجع من Admin
→ يرسل للمدير التنفيذي
→ Executive يقر أو يطلب مراجعة
→ السكرتير يغلق
```

## الدرجات

### HR

- حضور وانصراف 20.
- صلاة المسجد 5.
- حلقة الشيخ وليد 5.

### المدير

- أهداف 40.
- كفاءة 20.
- سلوك 5.
- مبادرات 5.

## القيود

- الموظف يرى نفسه فقط.
- Executive لا يتم تقييمه.
- المدير لا يعدل HR.
- HR لا يعدل المدير.
- السكرتير يدير الدورة من الويب.
- Executive لا يكتب الدرجات.
- Self score منفصل عن النهائي.

## التقنية

- State machine واضحة.
- HR task وManager task متوازيتان.
- Barrier.
- Version locking.
- Audit قبل/بعد.
- Return with reason.
- Notifications لكل مرحلة.
- Feature flag للانتقال.

## الحالات

- SELF_DRAFT.
- SELF_SUBMITTED.
- HR_PENDING/COMPLETED.
- MANAGER_PENDING/COMPLETED.
- PARALLEL_REVIEWS_COMPLETED.
- SECRETARY_REVIEW.
- RETURNED_*.
- SENT_TO_EXECUTIVE.
- EXECUTIVE_ACKNOWLEDGED/REVIEW_REQUESTED.
- CLOSED.

## اختبارات

- RLS self-only.
- العمل المتوازي دون overwrite.
- لا انتقال قبل اكتمال الجانبين.
- Return paths.
- الدرجة =100 كحد أقصى.
- الهاتف/الويب/التقرير متطابق.
- المدير التنفيذي مستثنى.
